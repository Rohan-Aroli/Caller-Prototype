================================================
PROJECT STATUS & ARCHITECTURE
================================================
Caller-AI Platform
This project is an AI calling platform. The current implementation features a resilient, high-throughput CSV lead ingestion pipeline with a full-stack architecture.

- Backend: Python, FastAPI, Pydantic. It provides an endpoint `/api/v1/leads/upload-csv` which parses, cleans, and validates CSV data synchronously using the standard library `csv` module (no pandas to keep it lightweight).
- Frontend: React 19, Vite, TypeScript, Tailwind CSS v4. Features a modern dark-theme UI with a drag-and-drop file upload and a Results Dashboard powered by Recharts and PapaParse (for CSV exporting).
- Architecture: Strict separation of concerns on the backend (api/routes, schemas, services, core) and isolated frontend component structure.

================================================
PREREQUISITES & SETUP
================================================
Prerequisites:
- Python >= 3.8
- Node.js >= 18
- npm

Setup Workflow:
The repository includes a unified, idempotent setup script that provisions both the backend and the frontend environments cleanly:
`python scripts/setup.py`

This script will:
1. Create a Python virtual environment (`.venv`) if one doesn't exist.
2. Install Python backend dependencies from `requirements.txt`.
3. Check for `node` and `npm` on the system.
4. Install frontend dependencies inside `frontend/` using `npm install`.
5. Create a `frontend/.env` file from `frontend/.env.example` if it doesn't already exist.

================================================
RUNNING THE APPLICATION
================================================
Backend (runs on http://localhost:8000):
`venv/bin/uvicorn backend.app.main:app --reload`

Frontend (runs on http://localhost:5173):
Inside frontend directory run `npm install` and then `npm run dev` in a background process or terminal tab.

================================================
TESTING
================================================
Backend Tests (Pytest):
`PYTHONPATH=$(pwd) .venv/bin/pytest backend/tests/`

================================================
ENVIRONMENT VARIABLES
================================================
Frontend:
- `VITE_API_BASE_URL`: URL to the FastAPI backend (e.g., `http://localhost:8000`). Configured in `frontend/.env`.

Backend:
- Configured via `backend/app/core/config.py` (BaseSettings)
- Allows CORS origins for local development (http://localhost:5173).
