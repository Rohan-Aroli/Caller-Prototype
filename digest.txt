# AI Calling Platform - CSV Lead Upload

This is the backend component of an AI calling platform, featuring a resilient, high-throughput CSV lead ingestion and validation pipeline.

## Setup

To set up the project (create a virtual environment and install dependencies), simply run the setup script:

```bash
python scripts/setup.py
```

## Running the application

To run the backend server using `uvicorn`:

```bash
# On Linux/macOS:
.venv/bin/uvicorn backend.app.main:app --reload

# On Windows:
.venv\Scripts\uvicorn backend.app.main:app --reload
```

The API will be available at `http://localhost:8000`.

## API Documentation & Health Check

- Health Check: `http://localhost:8000/health`
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

## Running Tests

To run the automated tests (`pytest.ini` automatically configures module resolution):

```bash
# On Linux/macOS:
.venv/bin/pytest

# On Windows:
.venv\Scripts\pytest
```

## Full-Stack Development Setup

This repository now includes both the FastAPI backend and a Vite+React frontend, providing an end-to-end platform for CSV lead upload.

### Prerequisites

- Python >= 3.8
- Node.js >= 18
- npm

### Repository Structure

- `backend/` - Contains the FastAPI backend application.
- `frontend/` - Contains the React Vite frontend web application.
- `scripts/` - Scripts for project initialization.
- `tests/` - Backend tests.

### First-time Setup Instructions

To setup both the backend and frontend at once, execute the unified setup script from the repository root:

```bash
python scripts/setup.py
```
This script will:
1. Create a Python virtual environment for the backend (`.venv`).
2. Install Python backend dependencies.
3. Install Node.js frontend dependencies via `npm`.
4. Copy the frontend `.env.example` file to `.env`.

### Commands to Start the Backend

Run the backend server using `uvicorn`:

```bash
# On Linux/macOS:
.venv/bin/uvicorn backend.app.main:app --reload

# On Windows:
.venv\Scripts\uvicorn backend.app.main:app --reload
```
The backend API will run at `http://localhost:8000`.

### Commands to Start the Frontend

In a new terminal tab, navigate to the `frontend/` directory and run:

```bash
cd frontend
npm run dev --host
```
The frontend web app will typically be available at `http://localhost:5173`.

### Required Environment Variables

**Backend (Root `.env`)**:
A `.env` file is generated in the root directory during setup for Telephony & Gemini variables. You must populate it with your credentials:
- `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_FROM_NUMBER`: Get these from your Twilio Console.
- `GEMINI_API_KEY`: Get this from Google AI Studio.
- `SERVER_DOMAIN`: The public domain of your backend (e.g., `your-subdomain.ngrok-free.app`). Required for Twilio to reach your local server.

**Frontend**: A `.env` file is generated inside the `frontend` folder containing:
`VITE_API_BASE_URL=http://localhost:8000`
You can modify this if your backend listens on a different port.

### Real-Time Voice Calls

The backend now supports real-time voice calls by bridging Twilio WebSockets directly with the Gemini Multimodal Live API.

1. **Expose Localhost via ngrok**:
   To receive Twilio Webhooks on your local machine, run:
   ```bash
   ngrok http 8000
   ```
   Then set `SERVER_DOMAIN` in your root `.env` to the ngrok forwarding domain (e.g., `1234-abcd.ngrok-free.app`), without `http://` or `https://`.

2. **Triggering a Call**:
   You can trigger a call by sending a POST request to `/api/v1/calls/trigger-call`:
   ```json
   {
       "phone_number": "+1234567890"
   }
   ```
   When the user answers, Twilio requests TwiML from `/api/v1/calls/twiml`, which connects them to the `/api/v1/calls/media-stream` WebSocket for a real-time conversation powered by Gemini!

### CSV Upload Workflow

1. Navigate to the frontend UI (`http://localhost:5173`).
2. Enter an "Agent ID" in the text field.
3. Select a `.csv` file.
4. Click "Upload" to submit to the backend endpoint (`/api/v1/leads/upload-csv`).
5. Wait for the success or error response which will parse and validate CSV contents synchronously.

### Troubleshooting Guidance

- **Frontend doesn't connect to backend**: Ensure CORS is configured properly in `backend/app/main.py`. The backend should allow origins `http://localhost:5173`. Make sure the frontend `.env` points to the correct backend port.
- **Node.js dependencies missing**: Rerun `npm install` inside the `frontend` directory manually if the setup script fails.
- **Python environments misconfigured**: Ensure you are executing commands with `.venv/bin/python` or similar relative paths to isolate packages. If corrupted, remove the `.venv` folder and run `python scripts/setup.py` again.

import logging
from fastapi import APIRouter, HTTPException, WebSocket, Request, Response
from pydantic import BaseModel
from twilio.request_validator import RequestValidator

from backend.app.services.telephony import telephony_provider
from backend.app.core.config import settings

logger = logging.getLogger(__name__)

router = APIRouter()

class CallRequest(BaseModel):
    phone_number: str

async def verify_twilio_request(request: Request) -> bool:
    """
    Validates that the incoming HTTP request actually originated from Twilio.
    Returns True if valid or if verification is turned off in settings.
    """
    if not settings.VERIFY_TWILIO_SIGNATURE or not settings.TWILIO_AUTH_TOKEN:
        return True

    signature = request.headers.get("X-Twilio-Signature")
    if not signature:
        return False

    validator = RequestValidator(settings.TWILIO_AUTH_TOKEN)
    url = str(request.url)

    # For POST requests, include the form body
    if request.method == "POST":
        form_data = await request.form()
        params = dict(form_data)
    else:
        params = dict(request.query_params)

    return validator.validate(url, params, signature)

@router.post("/trigger-call")
async def trigger_call(request: CallRequest):
    """
    Initiate an outbound call to the provided phone number.
    """
    try:
        call_sid = telephony_provider.trigger_call(request.phone_number)
        return {"status": "success", "call_sid": call_sid}
    except ValueError as e:
        logger.warning(f"Configuration or validation error triggering call: {e}")
        raise HTTPException(status_code=400, detail=str(e))
    except Exception as e:
        logger.error(f"Failed to trigger call: {e}")
        raise HTTPException(status_code=500, detail=str(e))

@router.post("/twiml")
@router.get("/twiml")
async def get_twiml(request: Request):
    """
    Returns TwiML to route the answered call to the Media Stream (WebSocket).
    """
    if not await verify_twilio_request(request):
        logger.warning("Rejected unverified request to /twiml")
        raise HTTPException(status_code=403, detail="Twilio signature verification failed.")

    if not settings.SERVER_DOMAIN:
        raise HTTPException(status_code=500, detail="SERVER_DOMAIN not configured.")

    clean_domain = settings.SERVER_DOMAIN.replace("https://", "").replace("http://", "").strip("/")
    ws_url = f"wss://{clean_domain}{settings.api_v1_str}/calls/media-stream"

    twiml_response = f"""<?xml version="1.0" encoding="UTF-8"?>
<Response>
    <Connect>
        <Stream url="{ws_url}" />
    </Connect>
</Response>"""

    return Response(content=twiml_response, media_type="application/xml")

@router.websocket("/media-stream")
async def media_stream(websocket: WebSocket):
    """
    WebSocket endpoint for Twilio Media Stream.
    """
    await telephony_provider.handle_media_stream(websocket)

import io
from fastapi import APIRouter, UploadFile, File, Form, HTTPException
from starlette.concurrency import run_in_threadpool
from backend.app.schemas.leads import CsvProcessingResponse
from backend.app.services.csv_processor import process_csv
from backend.app.core.config import settings

router = APIRouter()

ALLOWED_CONTENT_TYPES = {
    "text/csv",
    "application/vnd.ms-excel",
    "application/csv",
    "text/x-csv",
    "application/x-csv",
}

@router.post("/upload-csv", response_model=CsvProcessingResponse)
async def upload_csv(
    file: UploadFile = File(...),
    agent_id: str = Form(...)
):
    if not agent_id.strip():
        raise HTTPException(status_code=400, detail="agent_id cannot be empty.")

    if not file.filename:
        raise HTTPException(status_code=400, detail="Missing file.")

    is_csv_content_type = file.content_type in ALLOWED_CONTENT_TYPES
    is_csv_extension = file.filename.lower().endswith(".csv")

    if not is_csv_content_type and not is_csv_extension:
        raise HTTPException(status_code=400, detail="Unsupported file type.")

    # Guard against memory exhaustion DoS by chunked read with max size check
    chunk_size = 1024 * 1024  # 1 MB chunk
    chunks = []
    total_bytes = 0
    while True:
        chunk = await file.read(chunk_size)
        if not chunk:
            break
        total_bytes += len(chunk)
        if total_bytes > settings.max_upload_size_bytes:
            raise HTTPException(
                status_code=413,
                detail=f"File exceeds maximum allowed size of {settings.max_upload_size_bytes // (1024 * 1024)}MB."
            )
        chunks.append(chunk)

    if not chunks or total_bytes == 0:
        raise HTTPException(status_code=400, detail="File is empty.")

    content = b"".join(chunks)

    # Use BytesIO and TextIOWrapper with utf-8-sig to decode on-the-fly and handle BOM
    file_obj = io.TextIOWrapper(io.BytesIO(content), encoding="utf-8-sig")

    # Run CPU-bound CSV processing in worker thread pool so asyncio event loop is not blocked
    return await run_in_threadpool(process_csv, file_obj, agent_id)

import csv
import re
import sys
from typing import TextIO, List
from fastapi import HTTPException
from backend.app.schemas.leads import CsvProcessingResponse, AcceptedLead, RejectedRow

REQUIRED_HEADERS = {"name", "phone"}

# Pre-compiled regular expressions for maximum row-processing throughput
RE_PHONE_STRIP = re.compile(r'[\s\-\(\)\.]')
RE_E164 = re.compile(r'^\+[1-9]\d{7,14}$')

# Increase CSV field size limit to handle large freeform values safely
try:
    csv.field_size_limit(sys.maxsize)
except OverflowError:
    csv.field_size_limit(2147483647)

def normalize_header(header: str) -> str:
    return header.strip().lower().replace(" ", "_")

def normalize_phone(phone: str) -> str:
    phone = RE_PHONE_STRIP.sub('', phone)
    if phone.startswith("00"):
        phone = "+" + phone[2:]
    return phone

def is_valid_phone(phone: str) -> bool:
    # E.164: + followed by 8-15 digits, first digit non-zero
    return bool(RE_E164.match(phone))

def process_csv(file_obj: TextIO, agent_id: str) -> CsvProcessingResponse:
    try:
        reader = csv.reader(file_obj)
        try:
            raw_headers = next(reader)
        except StopIteration:
            raise HTTPException(status_code=400, detail="File is empty.")

        # Handle completely blank header row or empty list
        if not raw_headers or all(not h.strip() for h in raw_headers):
            raise HTTPException(status_code=400, detail="No headers found.")

        # Normalize headers
        normalized_headers = [normalize_header(h) for h in raw_headers]

        # Check for duplicates
        if len(normalized_headers) != len(set(normalized_headers)):
            raise HTTPException(status_code=400, detail="Duplicate headers found after normalization.")

        # Check for required headers
        missing_headers = REQUIRED_HEADERS - set(normalized_headers)
        if missing_headers:
            raise HTTPException(status_code=400, detail=f"Missing required headers: {', '.join(missing_headers)}")

        header_count = len(normalized_headers)
        name_idx = normalized_headers.index("name")
        phone_idx = normalized_headers.index("phone")

        extra_field_indices = [
            i for i, h in enumerate(normalized_headers) if h not in REQUIRED_HEADERS
        ]

        accepted_leads: List[AcceptedLead] = []
        rejected_rows: List[RejectedRow] = []

        row_number = 1  # Header is row 1

        for row in reader:
            row_number += 1

            # Ignore completely blank rows
            if not row or all(not cell.strip() for cell in row):
                continue

            errors = []

            if len(row) != header_count:
                errors.append(f"Expected {header_count} columns, but got {len(row)}.")
                rejected_rows.append(RejectedRow(row_number=row_number, errors=errors))
                continue

            name = row[name_idx].strip()
            if not name:
                errors.append("Name cannot be empty.")

            raw_phone = row[phone_idx].strip()
            phone = normalize_phone(raw_phone)
            if not is_valid_phone(phone):
                errors.append("Phone number is invalid. Must be in E.164 format.")

            if errors:
                rejected_rows.append(RejectedRow(row_number=row_number, errors=errors))
            else:
                extra_fields = {
                    normalized_headers[i]: row[i].strip() for i in extra_field_indices
                }
                accepted_leads.append(
                    AcceptedLead(
                        row_number=row_number,
                        name=name,
                        phone=phone,
                        extra_fields=extra_fields,
                        assigned_agent_id=agent_id
                    )
                )

        if len(accepted_leads) + len(rejected_rows) == 0:
            raise HTTPException(status_code=400, detail="File contains no data rows.")

        return CsvProcessingResponse(
            status="processed",
            agent_id=agent_id,
            total_rows=len(accepted_leads) + len(rejected_rows),
            accepted_count=len(accepted_leads),
            rejected_count=len(rejected_rows),
            accepted_leads=accepted_leads,
            rejected_rows=rejected_rows
        )

    except UnicodeDecodeError:
        raise HTTPException(status_code=400, detail="File must be UTF-8 encoded.")
    except csv.Error as e:
        raise HTTPException(status_code=400, detail=f"Malformed CSV: {str(e)}")

import json
import base64
import asyncio
import logging
from typing import Optional, List
from twilio.rest import Client
from fastapi import WebSocket, WebSocketDisconnect
import google.generativeai as genai
from deepgram import AsyncDeepgramClient
from deepgram.core.events import EventType
from deepgram.listen.v1.types.listen_v1results import ListenV1Results
from elevenlabs.client import AsyncElevenLabs

# Import audioop safely (supporting Python 3.13+ if audioop-lts is installed)
try:
    import audioop
except ImportError:
    try:
        import audioop_lts as audioop  # type: ignore
    except ImportError:
        raise ImportError(
            "audioop is required for Twilio mu-law audio conversion. "
            "Please ensure you are running on Python <= 3.12 or install 'audioop-lts'."
        )

from backend.app.core.config import settings

logger = logging.getLogger(__name__)

class TwilioProvider:
    def __init__(self):
        # Audio configuration
        self.twilio_sample_rate = 8000
        self.sample_width = 2  # 16-bit linear PCM width

        # Initialize Google Generative AI client once if API key is present
        if settings.GEMINI_API_KEY:
            genai.configure(api_key=settings.GEMINI_API_KEY)

    @property
    def client(self) -> Optional[Client]:
        """Dynamically instantiate or reuse Twilio Client so .env changes are respected."""
        if settings.TWILIO_ACCOUNT_SID and settings.TWILIO_AUTH_TOKEN:
            return Client(settings.TWILIO_ACCOUNT_SID, settings.TWILIO_AUTH_TOKEN)
        return None

    def trigger_call(self, to_number: str) -> str:
        client = self.client
        if not client:
            raise ValueError("TWILIO_ACCOUNT_SID and TWILIO_AUTH_TOKEN must be configured in .env.")

        if not settings.TWILIO_FROM_NUMBER:
            raise ValueError("TWILIO_FROM_NUMBER must be configured in .env.")

        if not settings.SERVER_DOMAIN:
            raise ValueError("SERVER_DOMAIN is not set. A public domain (e.g. ngrok) is required for Twilio webhooks.")

        # Strip any accidental http:// or https:// from domain
        clean_domain = settings.SERVER_DOMAIN.replace("https://", "").replace("http://", "").strip("/")
        twiml_url = f"https://{clean_domain}{settings.api_v1_str}/calls/twiml"

        call = client.calls.create(
            to=to_number,
            from_=settings.TWILIO_FROM_NUMBER,
            url=twiml_url
        )
        return call.sid

    async def _generate_llm_response(self, chat_session, user_text: str) -> str:
        """Query standard Gemini 2.0 Flash via text prompting."""
        try:
            response = await chat_session.send_message_async(user_text)
            return response.text.strip() if response and response.text else ""
        except Exception as e:
            logger.error(f"Gemini LLM error: {e}")
            return "I apologize, I had trouble processing that. Could you please repeat?"

    async def _synthesize_and_stream_to_twilio(
        self,
        text: str,
        eleven_client: AsyncElevenLabs,
        twilio_ws: WebSocket,
        stream_sid: str
    ):
        """
        Sends text to ElevenLabs TTS and streams the resulting audio back to Twilio.
        Requests ulaw_8000 format directly if possible, or resamples PCM 16kHz to 8kHz mu-law.
        """
        if not text.strip():
            return

        try:
            voice_id = settings.ELEVENLABS_VOICE_ID or "21m00Tcm4TlvDq8ikWAM"
            
            # Request ulaw_8000 directly from ElevenLabs for optimal latency and zero resampling overhead
            audio_stream = eleven_client.text_to_speech.convert(
                voice_id=voice_id,
                text=text,
                output_format="ulaw_8000",
                model_id="eleven_turbo_v2_5"
            )

            # Send in 20ms chunks (160 bytes for 8kHz mu-law) to preserve Twilio telephony pacing
            chunk_size = 160
            buffer = bytearray()

            async for chunk in audio_stream:
                if not chunk:
                    continue
                buffer.extend(chunk)

                while len(buffer) >= chunk_size:
                    slice_data = bytes(buffer[:chunk_size])
                    del buffer[:chunk_size]

                    media_msg = {
                        "event": "media",
                        "streamSid": stream_sid,
                        "media": {
                            "payload": base64.b64encode(slice_data).decode("utf-8")
                        }
                    }
                    await twilio_ws.send_json(media_msg)
                    await asyncio.sleep(0.018)  # Pace at ~20ms per 160-byte audio frame

            # Flush any remaining audio in buffer
            if buffer:
                media_msg = {
                    "event": "media",
                    "streamSid": stream_sid,
                    "media": {
                        "payload": base64.b64encode(bytes(buffer)).decode("utf-8")
                    }
                }
                await twilio_ws.send_json(media_msg)

        except Exception as e:
            logger.error(f"ElevenLabs TTS / Twilio playback error: {e}")

    async def handle_media_stream(self, twilio_ws: WebSocket):
        """
        Accepts Twilio WebSocket and runs a chained pipeline:
        1. STT: Streams Twilio 8kHz mu-law audio to Deepgram Live WebSocket.
        2. LLM: Triggers Gemini 2.0 Flash REST upon speech_final / is_final detection.
        3. TTS: Synthesizes response using ElevenLabs and streams 8kHz mu-law back to Twilio.
        """
        await twilio_ws.accept()

        # Validate necessary API keys
        if not settings.DEEPGRAM_API_KEY:
            logger.error("DEEPGRAM_API_KEY is not configured in .env.")
            await twilio_ws.close(code=1008, reason="DEEPGRAM_API_KEY is not configured.")
            return

        if not settings.GEMINI_API_KEY:
            logger.error("GEMINI_API_KEY is not configured in .env.")
            await twilio_ws.close(code=1008, reason="GEMINI_API_KEY is not configured.")
            return

        if not settings.ELEVENLABS_API_KEY:
            logger.error("ELEVENLABS_API_KEY is not configured in .env.")
            await twilio_ws.close(code=1008, reason="ELEVENLABS_API_KEY is not configured.")
            return

        # Initialize Clients
        genai.configure(api_key=settings.GEMINI_API_KEY)
        model = genai.GenerativeModel(
            model_name="gemini-3.1-flash-lite",
            system_instruction=(
                "You are an AI phone assistant for an inbound/outbound call. "
                "Keep responses concise, natural, conversational, and direct (1-2 sentences), "
                "suitable for spoken conversation over a phone call."
            )
        )
        chat_session = model.start_chat(history=[])

        dg_client = AsyncDeepgramClient(api_key=settings.DEEPGRAM_API_KEY)
        eleven_client = AsyncElevenLabs(api_key=settings.ELEVENLABS_API_KEY)

        stream_sid: Optional[str] = None
        stream_ready = asyncio.Event()
        processing_lock = asyncio.Lock()

        # Connect to Deepgram Live WebSocket configured for 8kHz mu-law
        try:
            async with dg_client.listen.v1.connect(
                model="nova-2",
                encoding="mulaw",
                sample_rate=8000,
                channels=1,
                endpointing=300,
                smart_format=True
            ) as dg_socket:

                # Callback for Deepgram transcription results
                async def on_deepgram_message(message):
                    nonlocal stream_sid
                    try:
                        if not isinstance(message, ListenV1Results):
                            return

                        is_final = getattr(message, "is_final", False)
                        speech_final = getattr(message, "speech_final", False)

                        if not (is_final or speech_final):
                            return

                        channel = getattr(message, "channel", None)
                        if not channel or not channel.alternatives:
                            return

                        transcript = channel.alternatives[0].transcript.strip()
                        if not transcript:
                            return

                        logger.info(f"User Transcribed: {transcript} (speech_final={speech_final}, is_final={is_final})")

                        # Trigger LLM -> TTS pipeline asynchronously under lock to avoid overlapping audio
                        async def run_pipeline():
                            async with processing_lock:
                                if not stream_sid:
                                    return
                                # 1. Query Gemini text LLM
                                reply_text = await self._generate_llm_response(chat_session, transcript)
                                logger.info(f"AI Response: {reply_text}")

                                # 2. Synthesize with ElevenLabs and stream to Twilio
                                await self._synthesize_and_stream_to_twilio(
                                    reply_text,
                                    eleven_client,
                                    twilio_ws,
                                    stream_sid
                                )

                        asyncio.create_task(run_pipeline())

                    except Exception as e:
                        logger.error(f"Error processing Deepgram message: {e}")

                dg_socket.on(EventType.MESSAGE, on_deepgram_message)

                # Start Deepgram listener task
                dg_listener_task = asyncio.create_task(dg_socket.start_listening())

                # Task to read audio from Twilio and pipe into Deepgram
                async def twilio_to_deepgram():
                    nonlocal stream_sid
                    try:
                        while True:
                            msg = await twilio_ws.receive_json()
                            event = msg.get("event")

                            if event == "start":
                                stream_sid = msg["start"]["streamSid"]
                                stream_ready.set()
                                logger.info(f"Twilio stream started with streamSid: {stream_sid}")
                            elif event == "media":
                                payload = msg["media"]["payload"]
                                audio_mulaw = base64.b64decode(payload)
                                # Send raw 8kHz mu-law audio directly to Deepgram
                                await dg_socket.send_media(audio_mulaw)
                            elif event == "stop":
                                logger.info(f"Twilio stream stopped: {stream_sid}")
                                break

                    except WebSocketDisconnect:
                        logger.info("Twilio WebSocket disconnected.")
                    except Exception as e:
                        logger.error(f"Error in twilio_to_deepgram: {e}")

                twilio_task = asyncio.create_task(twilio_to_deepgram())

                # Wait until Twilio or Deepgram completes
                done, pending = await asyncio.wait(
                    [twilio_task, dg_listener_task],
                    return_when=asyncio.FIRST_COMPLETED
                )

                for task in pending:
                    task.cancel()

        except Exception as e:
            logger.error(f"Error during audio stream processing: {e}")
            try:
                await twilio_ws.close()
            except Exception:
                pass

import { useState } from 'react';
import { Header } from './components/Header';
import { UploadForm } from './components/UploadForm';
import { Dashboard } from './components/Dashboard';
import type { CsvProcessingResponse } from './types';
import './index.css';

function App() {
  const [loading, setLoading] = useState<boolean>(false);
  const [result, setResult] = useState<CsvProcessingResponse | null>(null);
  const [globalError, setGlobalError] = useState<string>('');

  const handleUpload = async (file: File, agentId: string) => {
    setLoading(true);
    setGlobalError('');
    setResult(null);

    const formData = new FormData();
    formData.append('file', file);
    formData.append('agent_id', agentId);

    const baseUrl = import.meta.env.VITE_API_BASE_URL || 'http://localhost:8000';

    try {
      const response = await fetch(`${baseUrl}/api/v1/leads/upload-csv`, {
        method: 'POST',
        body: formData,
      });

      const data = await response.json();

      if (response.ok) {
        setResult(data as CsvProcessingResponse);
      } else {
        setGlobalError(data.detail || 'Failed to validate CSV due to server error.');
      }
    } catch (err) {
      console.error(err);
      setGlobalError('Error connecting to the validation server. Please try again later.');
    } finally {
      setLoading(false);
    }
  };

  const handleReset = () => {
    setResult(null);
    setGlobalError('');
  };

  return (
    <div className="min-h-screen bg-gray-900 text-white flex flex-col font-sans selection:bg-accent/30">
      <Header />

      <main className="flex-1 flex flex-col py-12 px-4 sm:px-6 lg:px-8">
        <div className="max-w-7xl mx-auto w-full flex-1 flex flex-col">

          {!result ? (
            <div className="flex-1 flex flex-col items-center justify-center space-y-12 max-w-3xl mx-auto w-full animate-in fade-in slide-in-from-bottom-8 duration-700">
              <div className="text-center space-y-4">
                <h1 className="text-4xl md:text-5xl font-extrabold tracking-tight text-white">
                  Validate Your Leads
                </h1>
                <p className="text-lg md:text-xl text-gray-400 max-w-2xl mx-auto">
                  Upload your CSV file to instantly clean, parse, and validate lead data before import.
                </p>
              </div>

              <UploadForm onUpload={handleUpload} loading={loading} />

              {globalError && (
                <div className="w-full max-w-2xl p-4 bg-error/10 border border-error/20 rounded-lg text-error text-center shadow-lg shadow-error/5">
                  <p className="font-medium">{globalError}</p>
                </div>
              )}
            </div>
          ) : (
            <Dashboard data={result} onReset={handleReset} />
          )}

        </div>
      </main>
    </div>
  );
}

export default App;

import React, { useState, useRef } from 'react';

interface UploadFormProps {
  onUpload: (file: File, agentId: string) => Promise<void>;
  loading: boolean;
}

export function UploadForm({ onUpload, loading }: UploadFormProps) {
  const [file, setFile] = useState<File | null>(null);
  const [agentId, setAgentId] = useState<string>('');
  const [dragActive, setDragActive] = useState<boolean>(false);
  const [error, setError] = useState<string>('');
  const fileInputRef = useRef<HTMLInputElement>(null);

  const handleDrag = (e: React.DragEvent) => {
    e.preventDefault();
    e.stopPropagation();
    if (e.type === "dragenter" || e.type === "dragover") {
      setDragActive(true);
    } else if (e.type === "dragleave") {
      setDragActive(false);
    }
  };

  const handleDrop = (e: React.DragEvent) => {
    e.preventDefault();
    e.stopPropagation();
    setDragActive(false);

    if (e.dataTransfer.files && e.dataTransfer.files[0]) {
      const droppedFile = e.dataTransfer.files[0];
      if (droppedFile.name.endsWith('.csv')) {
        setFile(droppedFile);
        setError('');
      } else {
        setError('Please upload a valid .csv file');
      }
    }
  };

  const handleChange = (e: React.ChangeEvent<HTMLInputElement>) => {
    e.preventDefault();
    if (e.target.files && e.target.files[0]) {
      const selectedFile = e.target.files[0];
      if (selectedFile.name.endsWith('.csv')) {
        setFile(selectedFile);
        setError('');
      } else {
        setError('Please upload a valid .csv file');
      }
    }
  };

  const onButtonClick = () => {
    fileInputRef.current?.click();
  };

  const handleSubmit = (e: React.FormEvent) => {
    e.preventDefault();
    if (!file) {
      setError('Please select a file to upload');
      return;
    }
    if (!agentId.trim()) {
      setError('Agent ID is required');
      return;
    }
    setError('');
    onUpload(file, agentId);
  };

  const formatFileSize = (bytes: number) => {
    if (bytes === 0) return '0 Bytes';
    const k = 1024;
    const sizes = ['Bytes', 'KB', 'MB', 'GB'];
    const i = Math.floor(Math.log(bytes) / Math.log(k));
    return parseFloat((bytes / Math.pow(k, i)).toFixed(2)) + ' ' + sizes[i];
  };

  return (
    <form onSubmit={handleSubmit} className="w-full max-w-2xl mx-auto space-y-6">
      <div className="space-y-2">
        <label htmlFor="agentId" className="block text-sm font-medium text-gray-300">
          Agent ID
        </label>
        <input
          type="text"
          id="agentId"
          value={agentId}
          onChange={(e) => setAgentId(e.target.value)}
          placeholder="e.g. agt_12345"
          className="w-full bg-gray-800 border border-gray-700 rounded-lg px-4 py-3 text-white placeholder-gray-500 focus:outline-none focus:ring-2 focus:ring-accent focus:border-transparent transition-all"
          disabled={loading}
        />
      </div>

      <div className="space-y-2">
        <label className="block text-sm font-medium text-gray-300">
          Lead Data (CSV)
        </label>
        <div
          className={`relative border-2 border-dashed rounded-xl p-8 transition-all ${
            dragActive
              ? 'border-accent bg-accent/10'
              : 'border-gray-700 bg-gray-800/50 hover:bg-gray-800'
          } ${file ? 'border-success/50 bg-success/5' : ''}`}
          onDragEnter={handleDrag}
          onDragLeave={handleDrag}
          onDragOver={handleDrag}
          onDrop={handleDrop}
        >
          <input
            ref={fileInputRef}
            type="file"
            accept=".csv"
            onChange={handleChange}
            className="hidden"
            disabled={loading}
          />

          <div className="flex flex-col items-center justify-center text-center space-y-4">
            {file ? (
              <>
                <div className="p-3 bg-success/20 rounded-full text-success">

                </div>

      {error && (

#!/usr/bin/env python3
import os
import sys
import venv
import subprocess
from pathlib import Path

def print_message(msg: str, is_error: bool = False):
    prefix = "[ERROR]" if is_error else "[INFO]"
    print(f"{prefix} {msg}")

def main():
    root_dir = Path(__file__).resolve().parent.parent
    venv_dir = root_dir / ".venv"
    req_file = root_dir / "requirements.txt"

    if not req_file.exists():
        print_message(f"Dependency file not found at {req_file}", is_error=True)
        sys.exit(1)

    # 1. Create or reuse the virtual environment
    if not venv_dir.exists():
        print_message(f"Creating virtual environment at {venv_dir}...")
        try:
            # Create a virtual environment using the built-in venv module
            builder = venv.EnvBuilder(with_pip=True)
            builder.create(venv_dir)
            print_message("Virtual environment created successfully.")
        except Exception as e:
            print_message(f"Failed to create virtual environment: {e}", is_error=True)
            sys.exit(1)
    else:
        print_message(f"Found existing virtual environment at {venv_dir}. Reusing it.")

    # Determine pip path based on OS
    if os.name == 'nt':
        pip_path = venv_dir / "Scripts" / "pip.exe"
    else:
        pip_path = venv_dir / "bin" / "pip"

    if not pip_path.exists():
        print_message(f"Pip executable not found in virtual environment ({pip_path}). Environment might be corrupted.", is_error=True)
        sys.exit(1)

    # 2. Install dependencies
    print_message(f"Installing missing dependencies from {req_file.name}...")
    try:
        # We run pip install -r requirements.txt
        # pip inherently avoids reinstalling if the version satisfies the requirement
        result = subprocess.run(
            [str(pip_path), "install", "-r", str(req_file)],
            cwd=root_dir,
            check=True,
            capture_output=True,
            text=True
        )
        print_message("Dependencies installed successfully.")
        # Optional: Print output if needed
        # print(result.stdout)
    except subprocess.CalledProcessError as e:
        print_message(f"Failed to install dependencies: {e}", is_error=True)
        print_message(e.stderr, is_error=True)
        sys.exit(1)



    # 3. Create Root .env if it doesn't exist
    root_env_file = root_dir / ".env"
    if not root_env_file.exists():
        print_message(f"Generating root .env template at {root_env_file}...")
        try:
            with open(root_env_file, "w") as f:
                f.write("# Telephony & Gemini Configurations\n")
                f.write("TWILIO_ACCOUNT_SID=\n")
                f.write("TWILIO_AUTH_TOKEN=\n")
                f.write("TWILIO_FROM_NUMBER=\n")
                f.write("GEMINI_API_KEY=\n")
                f.write("SERVER_DOMAIN=\n")
            print_message("Root .env template created.")
        except Exception as e:
            print_message(f"Failed to create root .env file: {e}", is_error=True)

    # 4. Setup Frontend
    frontend_dir = root_dir / "frontend"
    if frontend_dir.exists() and (frontend_dir / "package.json").exists():
        print_message("Found frontend directory. Checking for Node.js...")
        try:
            subprocess.run(["node", "--version"], check=True, capture_output=True, text=True)
            subprocess.run(["npm", "--version"], check=True, capture_output=True, text=True)

            print_message("Installing frontend dependencies...")
            subprocess.run(
                ["npm", "install"],
                cwd=frontend_dir,
                check=True,
                capture_output=True,
                text=True
            )
            print_message("Frontend dependencies installed successfully.")

            # Copy .env.example to .env if .env doesn't exist
            env_example = frontend_dir / ".env.example"
            env_file = frontend_dir / ".env"
            if env_example.exists() and not env_file.exists():
                import shutil
                shutil.copy(env_example, env_file)
                print_message("Created frontend/.env from frontend/.env.example")

        except FileNotFoundError:
            print_message("Node.js or npm not found. Skipping frontend setup.", is_error=True)
        except subprocess.CalledProcessError as e:
            print_message(f"Failed to setup frontend: {e}", is_error=True)
            print_message(e.stderr, is_error=True)
            sys.exit(1)
    else:
        print_message("No frontend directory with package.json found. Skipping frontend setup.")

    print_message("Setup completed successfully.")

if __name__ == "__main__":
    main()
